# mbg-consulting

Site vitrine de Mattieu Bernard-Guêle — MBG Consulting, coach agile à Lille.

Site statique (un seul `index.html` + `assets/`), hébergé gratuitement sur GitHub Pages.

## Mettre en ligne
1. Settings → Pages → Source : *Deploy from a branch*, branche `main`, dossier `/ (root)`.
2. Le site est servi sur `https://<utilisateur>.github.io/mbg-consulting/`.
3. Nom de domaine perso (optionnel) : ajouter un fichier `CNAME` contenant le domaine, puis configurer le DNS chez le registrar.
